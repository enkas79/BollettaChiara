# BollettaChiara

Analizzatore di bollette Luce, Gas e Acqua da PDF: estrae i dati, mostra
tabella e grafici di andamento costi/consumi e permette l'export di un
riepilogo in PDF.

## Avvio

```bash
pip install -e ".[gui]"
python main.py
```
